# 波浪理论（专业解读版） The Wave Principle — 来源路由入口（compact pack）

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 基本面估值与财报分析
- 止损与仓位管理规程（原书未提供，需用户自备风控）
- 波浪幅度/点位的精确算法（原书无公式；点评者斐波那契参数未经核实）
- 盘整/无趋势行情的细节数浪（原书明确限定趋势市）
- 1938 年美股特有制度指标（NYSE 席位价格等）的直接套用

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 五浪推进+三浪调整的分形嵌套是一切判定的坐标系（九级浪级标注）
2. 通道作图法把'何时平仓'变成可执行的几何规程（浪2后画通道，浪4后锁定浪5终点）
3. 形态走完才有预警价值：右侧确认、跟随趋势，放弃左侧精准预测（作者与点评者共同警示）
4. 成交量与多周期是浪性判别与防骗的第二证据链（1/3/5放量、2/4缩量；周线对数/日线算术）
5. 每条规则自带例外条款：先过适用域闸门（五条件、趋势行情），再下判定
