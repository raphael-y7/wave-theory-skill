# 决策规则速查 — 波浪理论（专业解读版） The Wave Principle

| 能力 | 一句话规则 |
|---|---|
| 第五浪终点定位与终结判定（通道法三步+三联证） | 浪4走完后连浪2、浪4终点画基准线、过浪3顶点作平行上通道线，浪5止于该线附近即为平仓区；破上通道线+同级天量为终结确认，未破线且回落为走软预警。 |
| 波浪计数与九级浪级标注规范 | 先定主方向再数五浪（奇数拆五、偶数拆三、a-b-c 递归），用倾斜规则检验计数，按九级专名与表 1 符号逐级标注，单一标的独立计数。 |
| 六条递归持有卖出规则 | 已建仓者按"本级第四浪未走完/第五浪未耗尽不卖"逐级下钻核对至最内层第五浪，以"最内层第五浪耗尽+破上通道线（对数图）+同级天量"三证齐备处卖出。 |
| 调整浪四分类判别与强度预警 | 调整走完后按"浪B相对调整起点、浪C相对浪A低点"两个几何读数归入之字形/平台形/不规则形四类，再折算后市强度（之字=一般、平台=强势、终点高于a=超级强势；熊市镜像反向）。 |
| 延长浪识别与两次反转推演 | 驱动浪内细分出五个小浪即延长浪（一轮至多一个、最常浪5），它永非终点——其后先以三浪回延长浪起点（第一次反转），再顺大势且通常超延长幅度（第二次反转）；恰逢第五大浪走完则构成不规则A-B-C，浪C杀跌至前轮第五大浪起点附近。 |
| 量能验证与形态歧义裁决 | 量随浪序绑定（1/3/5放量、2/4与调整浪全程缩量）；"?"歧义处缩量判不规则B、放量判延长浪；浪5后量稳价微涨即反转预警；市场异常疲弱时量能证据降权 |
| 三角形判别与交替规则 | 三角形必含五浪且须嵌于行情浪位；楔形只作浪5；结束后沿浪2方向运行（楔形终点变向返回底部）；"画满"即近顶点、突破边线非必要条件；浪2/浪4调整形态互斥交替 |
| 失败浪与不规则顶应对 | 顶后回落再反弹越过正统顶（OT）创新高=不规则顶，最高价只是浪B、真顶在OT，浪C五浪杀跌指向先前第五大浪起点附近；第五浪未创新高即失败浪，B为真顶，B点附近立即清仓 |
| 熊市阶段诊断与长线建仓点确认 | 按六段序列定位熊市（OT-B不规则顶→五浪含延长→之字→三角形→追加浪/补充循环浪→自低点首轮五浪上升）；确认信号出现前一切低点只是候选底；自候选低点的首轮五浪上升且为更大级别浪1，即确认长线建仓点 |
| 多周期研判与图表尺度规则 | 快市用60分钟+日线、慢市升周线；周线对数图（放大2-3倍）、日线/60分钟算术图；高级别顶部验突破用算术图、底部用对数图；日线疑点一律用周线排除；同级别浪固定同图 |
| 波浪图20条总纲清单 | 读图先过20条四组自查（同步/通道/制图/数据），对浪数"感觉混淆不清"就停止给结论先重画 |
| 跨市场同步监测 | 同类市场顶部错落、底部几乎同步（底部共振=重大底确认），无关序列突然同步=大事预警，同步事件触发浪级定位复核 |
| 非价格序列波浪化三招 | 非价格数据先过数据关——无数据用逆指标、噪声大用替代序列、有季节性用十年基线去季节化，三招都不可行就停止 |
| 波浪理论适用域闸门与使用姿态 | 用波浪理论前先过三层闸门——五条件核对对象、只对趋势行情、只做宏观判定的右侧跟随，放弃精准预测 |
| 点评者实战心法（张艺博，非艾略特原文） | 点评者（张艺博）的实战经验合集——右侧确认、只做三浪三、弃弱留强、缩量介入，每条必须标注证据等级且声明非艾略特原文 |
