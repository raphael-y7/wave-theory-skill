# 熊市阶段诊断与长线建仓点确认（bear-diagnosis-skill）

## R — 原文依据

### 1. 熊市下跌的形态预告程序
> "从OT到B的不规则顶部，预示着市场将要出现一轮剧烈的下跌。而xa至xe的延长浪，可以使我们预测到，xb之后会紧跟着三浪下挫，这会使价格跌到xe之下的水平。……之字形调整浪A-B-C预示着……市场可能形成一个平台形调整浪或三角形调整浪。"（第九章，图64-66）

### 2. 半月形：加速赶底形态
> "这一轮波浪运动呈弧线形下落，而且最后几乎是竖直状态……指数下跌至115.82点的那段延长浪预示着市场可能会创出新低……波浪运行的速度非常快，所以比较适合用60分钟波动图来分析，特别是在后半段。"（第九章，图66-67）

### 3. 补充循环浪：三浪调整后额外五浪
> "市场在正常的三浪调整之后出现了额外下跌，走出了由五浪组成的浪C，最终到达调整运动的终点。此时的市场与1932年非常相似。"（第九章，补充循环浪节）

### 4. 长线建仓点及其确认信号
> "确定调整浪的终点也很重要，这个点被称为长线建仓点，投资者可以在这里再度建仓买入。"（第八章开篇）
> "平均指数从97.46点上涨至121.54点，完成了一轮上升五浪，这一段涨势又是更大级别波浪的第一浪。这同时也确认了1938年3月31日的97.46点，是熊市的浪A的底部。"（第九章，图68段落。注：原文误作"1937年"，据图66、图68横轴更正为1938年）

## I — 方法论自述

大级别第五浪之后，熊市不是一团混乱，而是一串可逐段定位的形态序列。本卡骨架＝"定位阶段→推演后市→守住确认信号"：

1. 阶段序列（1937-38年复盘提炼）：①OT之后浪B越过正统顶创新高（不规则顶）→预告剧烈下跌；②自B走五浪下跌、内含延长浪→预告跌到延长浪之下（伴生特征：下行平行四边形通道＝速度快、幅度大）；③之字形A-B-C走完→预告其后可能接平台形或三角形调整；④三角形收窄→再次确认更低价位；⑤正常三浪后额外走出五浪式浪C（"补充循环浪"，作者自创概念）或弧线加速的"半月形"→到达调整终点；⑥自低点出现首轮五浪上升→确认底部。
2. 每一步只做阶段定位与后市推演，不预测具体点位——序列给的是结构顺序，不是幅度公式。
3. 出口是终点确认：调整终点即"长线建仓点"；确认信号＝自候选低点走出一轮完整五浪上升（该五浪同时是更大级别的浪1）。确认之前，一切低点只是"候选底"。
4. 伴随姿态：阶段①-⑤期间防守为主；速度极快的末段（半月形）可下沉到60分钟图看结构。

## A1 — 原书案例

### 案例（作者转述，第九章图62-68）：1937-38熊市全程复盘与建仓点确认
输入：DJIA自1937年3月10日195.59点的整轮下跌；月线/日线/小时波动图。
执行（按阶段序列逐段定位）：
- 图62/63：整轮下跌分解为带圈A-E——A跌至163.31、B反弹190.38（低于起点195.59）、C跌至115.82、D于三角形末端上摸123.86、E追加浪直落97.46；
- 图64：自195.59五浪跌至163.31（浪A）后三浪上升，8月14日190.38越过OT（8月4日187.31）→不规则顶确立；
- 图65：浪C快跌至115.82（1937.10.19），下行平行四边形＋xa-xe延长浪→预示xb后三浪下挫、价格将低于xe；
- 图66/67：115.82反弹至132.86后"半月形"弧线跌至97.46（1938.3.31），末端近竖直，用60分钟图解析为五浪；作者称此为道指"第一次出现的补充循环浪"（1938.2.23-3.31自132跌至98，正常三浪后额外五浪式浪C）；
- 图68：1938年3月31日97.46起五浪升至4月18日121.54→确认97.46为熊市浪A底＝长线建仓点；其后平台形调整至5月27日106.44结束（原文此处年份同误，更正为1938年），不破前低，为持仓/再加仓窗口。
结论：阶段①-⑥全部兑现。辅以第六章统计（-50.1%、历时一年零三周；NYSE资金量-92.9%、成交量-87.5%）构成幅度/时间/量能三维底座。注：所有浪标系事后标注，实盘操作结果未说明。

## A2 — 未来触发

1. 情境：大级别下跌进行中，想知道熊市走到哪一步、后面还有什么。语言信号："现在熊市到哪个阶段了？""后面还有几浪？"（bear market stage, where are we）
2. 情境：三浪调整"走完"了，纠结能否抄底。语言信号："A-B-C走完了是不是见底了？"（three waves done, bottom?）
3. 情境：想确认长线建仓点。语言信号："怎么确认熊市底部？""长线建仓点在哪？"（long-term entry, bottom confirmation）
4. 情境：熊市中连续抢反弹被套。语言信号："反弹要不要做？"（bear rally trap）
5. 情境：跌势加速、弧线赶底。语言信号："加速下跌怎么办？"（half-moon, accelerating decline）

与相邻卡区分：
- 与 wave-five-end-skill：本卡管"熊市全程阶段定位＋建仓点"；wave-five-end-skill 管"单轮运动终点"（某一段上升运动的第五浪判定）。判断熊市里某段下跌的内部结构，不等于本卡的全局阶段定位。
- 与 correction-classifier-skill：本卡把形态序列当阶段坐标做全程诊断；单个调整形态属于哪类、强度如何归 correction-classifier-skill。
- 与 failure-irregular-top-skill：诊断链第一环"OT-B不规则顶"的形态细节与顶部应对由后者承担；本卡承接其结论继续向后推演。

## E — 执行步骤

输入契约（缺失先问）：较大级别第五浪已结束（或强烈怀疑）的前提＋当前下跌的多周期数据（至少周线＋日线）。缺浪级定位→先做九级浪级标注；缺数据周期→先要数据，不得只用单一周期定位阶段。

Step 1 阶段定位
- 按序列核对：①OT后B是否越过OT？②是否自B走五浪下跌、内有延长浪？③之字A-B-C是否走完？④是否接三角形？⑤是否出现追加浪/半月形/补充循环浪（三浪后额外五浪C）？
- 完成标准：当前走势定位到①-⑤中某一阶段，输出"阶段|证据|后市推演"表。
- 判停点1：三浪调整走完≠调整结束（1938年首例补充循环浪）——未出现⑤⑥结构一律维持防守，禁止仅凭"三浪已够"抄底。
- 判停点2：形态归属不清（事前判型难是作者自认缺口）→并列2-3个候选阶段与各自后市推演，明示不确定，不强行单选。

Step 2 底部候选与确认
- 结构上调整看似终结的低点→只标"候选底"。
- 等待自候选低点走出一轮完整五浪上升，且该五浪可判为更大级别的浪1→确认浪A底＝长线建仓点。
- 完成标准：五浪上升标注＋浪级归属说明；确认前的候选底一律不作为建仓依据输出。

Step 3 建仓后跟踪
- 确认后的平台形调整若不破候选低点（1938年例：121.54回落至106.44不破97.46）→持仓/再加仓窗口。
- 跌破候选低点→候选底失效，回Step 1重新定位。
- 完成标准：跟踪结论（有效/失效）＋失效处理动作。

输出契约：熊市阶段诊断表（阶段①-⑥|图形证据与价位日期|后市推演|操作姿态）＋建仓点确认记录（候选底价位、确认五浪、确认日期）＋不确定性声明。全部结论为结构研判，不构成点位预测。

## B — 边界

反例与失效边界（全部消化）：
1. 不规则顶陷阱（原文反例x-p3-03）：B越过OT创新高把"卖出后回补者"与"放心持有者"一网打尽，随后浪C五浪深杀——"新高＝趋势健康"直觉失效；预警信号：新高伴随量能萎缩、下跌起点说不清是浪5还是浪C。
2. 补充循环浪（原文反例x-p3-11）："三浪调整走完即调整结束"失效——1938年2-3月三浪完成后额外五浪C杀跌（半月形132→97，末端近竖直）；在三浪"完整"处抄底会承受最后加速段。一切"浪数计满＝趋势结束"的判定须留额外浪余量。
3. 【点评】猜顶猜底陷阱（反例x-p3-12）：底部往往在多数人忍无可忍放弃抵抗时才来；以情绪耐受度而非结构位置决定进出，系统性低卖高买——这正是要用确认信号而非感觉的原因（现代点评者主张，非艾略特原文）。
4. 【点评】熊市杀伤与休息纪律（反例x-p3-13）：熊市特征下资金"大幅且快速缩水"，抢B浪反弹死在反弹里、多数人在C浪绝望；熊市诊断的真实目标是存活而非抄底，识别阶段后宜休息（现代点评者主张，非艾略特原文）。

作者盲点与批判（阶段0）：
- 序列系事后标注：1937-38为一次样本、事后画线，事前判型作者自认困难；原书无实时数浪纪律、无多方案预案。
- 不可证伪风险："追加浪/补充循环浪"是遇到新走势时自创的补丁概念（现代理论归入双重三浪/联合调整），"异常即扩张"使判错可归为新概念而非规则失败。
- 全书无止损规程：确认信号本身也可能失效，失效后的退出预案需自行补足。
- 本书为1938年美股背景：阶段序列仅验证于一次熊市复盘，勿当普适频率表使用。

不适用：小级别回调定位；没有"大级别第五浪已结束"前提的普跌段；把诊断表当点位预测；以抄底冲动替代确认信号。
