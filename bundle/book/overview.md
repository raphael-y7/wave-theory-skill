## 1. 结构 (Structural)

### 类型
技术分析实操方法论（含自然哲学世界观包装 + 历史实证复盘）

### 一句话主旨
股市波动以"五浪推进 + 三浪调整"的分形嵌套结构运行，掌握其模式、浪级与通道作图法，即可在浪 2 结束后框定整轮运动、在第五浪终点附近平仓、在调整浪终点重新建仓。

### 骨架 (7 个一级论点及其关系)

1. **模式公理**：一轮完整市场运动 = 5 个浪（1/3/5 驱动 + 2/4 调整），调整浪内部呈 a-b-c（第一至三章）
2. **分形嵌套公理**：一个浪级的五浪构成更大级别的一个浪，"依此类推"；配九级浪级命名与表 1 符号体系（第二章、第四章）
3. **通道作图法**：浪 2 结束即可画初始通道，经两次重绘锁定浪 3/浪 4/浪 5 终点——浪 5 终点即平仓时点（第三章、第七章、第八章）
4. **终点形态学**：第五浪破上通道线 + 同级天量；延长浪及其后"两次反转"八规律；失败浪；不规则顶（第五章、第八章）
5. **调整形态学**：之字形/平台形/不规则形/三角形四大类判别几何 + 形态对后市强度的预警 + 交替规则（第五章）
6. **量能与图表配合**：速度-图表尺度匹配、成交量-浪序绑定（1/3/5 放量、2/4 缩量）、多周期研判矩阵（第六章、第七章）
7. **实战与实证**：六条递归卖出规则、1937-38 熊市逐浪复盘自证、十个非市场序列的波浪化推广（第八、九、十章）

**论点之间的关系**: 层层递进——公理（1/2）→ 工具（3）→ 形态规则（4/5）→ 验证工具（6）→ 操作闭环与普适化（7）。第七章 20 条图法总结是操作总纲。

### 作者要解决的核心问题
股市波动是否有规律、能否据此预测？具体落到两个决策点：**何时平仓**（第五浪终点）与**何时建仓**（较大级别调整浪终点）。

## 2. 解释 (Interpretive)

### 关键术语（作者本人的用法；完整词典由术语提取器产出 GLOSSARY）

| 术语 | 作者的定义 | 与常识差异 |
|---|---|---|
| 驱动浪/基本浪 | 奇数浪 1、3、5，与主方向同向，细分 5 个子浪 | 常识"主升浪"专指浪 3；此处 1/3/5 皆可承载延长 |
| 调整浪 | 偶数浪 2、4，逆向，细分 3 个子浪；走完后对后市强度有预警作用 | 常视为杂乱回调；此处是有形态学分类的预测结构 |
| 浪级 | 九级嵌套：次微浪→微浪→细浪→小浪→中浪→大浪→循环浪→超级循环浪→特大超级循环浪；相对级别，不绑定固定时间框架 | 常以长/中/短线混称 |
| 一轮完整运动 | 通常由五个浪构成的完整循环 | "通常"保留弹性 |
| 运行通道/基准线/上通道线 | 两条平行线界定波浪运行；浪 3 止于上通道线附近（穿越=强势/未达=弱势），浪 5 通常止于上通道线附近 | 兼作终点预测器与强弱判据，非普通阻力线 |
| 之字形/平台形/不规则形调整 | 三大类三浪调整：B/C 相对起点与 A 的位置判型；不规则形 B 超前顶（1929.9 只是 B 浪，真顶 1928.11） | "不规则顶"是本书最反直觉判定 |
| 三角形调整浪 | 必含五浪；水平四亚型 + 楔形两亚型；"楔形只会作为第五浪出现"；"画满"即近顶点 | 有严格位置约束，非普通整理形态 |
| 延长浪 | 被细分为五个小浪的驱动浪；浪 1/3/5 皆可，最常在浪 5；"永远不会是一轮运动的终点" | 结构事件，触发"两次反转"程序 |
| 两次反转（双重反转） | 延长浪后固定程序：先三浪回延长浪起点，再顺大势运行且通常超延长幅度 | 常识无此程序 |
| 失败浪 | 第五浪未创新高，B 为真顶，3 升 5 降八浪 | 即"双头"，但被解释为八浪循环变形 |
| 常规顶部（OT）/不规则顶部 | 第五浪正统终点 vs 浪 B 越过 OT 的顶部 | 区分"最高价顶"与"正统顶" |
| 追加浪/补充循环浪 | 调整结构外额外走出的浪 / 正常三浪后额外的五浪式浪 C 下跌 | 自创补丁概念，现代理论无对应名 |
| 强势调整/超级强势 | 平台形=强势；调整终点高于 a 低点=超级强势；熊市镜像"超级弱势" | 以形态与相对终点位置论强弱，非回调深度 |
| 对数/算术比率图 | 周线对数、日线/60 分钟算术；高级别顶部看算术、底部看对数 | 坐标尺度是判别工具，非偏好 |
| 波浪图/波动图 | 高低价棒线记录，供数浪与画通道 | 以最高/最低价定义浪形，非收盘价 K 线 |
| 换手率/席位价格 | 可被数浪的独立量能序列，用于长期循环定位 | 席位价格制度已亡，思路可迁移 |

### 核心命题（合并三部分笔记，去重后 16 条）

1. 股市波动是心理现象，受有序法则支配；波浪形态完备需五个条件（所有权分散、公开市场、数据可靠、信息可得、可绘图）
2. 一轮完整运动由五浪构成（3 驱动 + 2 调整）；"为什么会是五"是作者明示放弃解释的宇宙之谜
3. 分形嵌套：奇数浪细分 5 子浪、偶数浪细分 3 子浪；一个浪级的五浪 = 更大级别的一个浪
4. "股市到达顶点之前，一定会走完每一个浪级的第五浪"——终点可逐级下钻推算（作者宣称精确到"日和小时"）
5. 倾斜向上规则：浪 3 高于浪 1、浪 5 高于浪 3；浪 4 回调达不到浪 2 水平；浪 2/浪 4 很少吞没前浪全部涨幅
6. 通道法三步规程：浪 2 后画初始通道 → 浪 3 后重绘（穿越=暂时强势/未达=暂时弱势）→ 浪 4 后画最终通道锁定浪 5 终点
7. 第五浪终结三联证：突破上通道线（高级别须对数图验证）+ 同级天量 + 可能以不规则顶收场
8. 延长浪八规律（两次反转框架）：延长浪永非终点；其后先三浪回延长浪起点，再顺大势且通常超延长幅度；第五大浪顶遇延长 → 不规则 A-B-C 杀跌至第五大浪起点附近
9. 调整浪四大类判别几何（按 B/C 相对位置）+ 强度预警（之字=一般、平台=强势、终点抬高=超级强势）
10. 三角形规则束：必含五浪（不足五浪忽略）、楔形仅作浪 5、结束后沿浪 2 方向、中浪 5 成三角=反转预备、"画满"即近顶点
11. 交替规则：浪 2 与浪 4 的调整形态互斥分布（之字 ⇄ 平台/三角）
12. 失败浪：第五浪未创新高即 B 为真顶，应立即清仓（危险信号）
13. 成交量-浪序绑定：调整浪全程缩量；1/3/5 放量、2/4 缩量；浪 5 后量稳价微涨=反转在即；量能可裁决形态歧义（缩量=不规则 B，放量=延长浪）
14. 递归持有规则：不到本级第五浪（含细分第五浪）不卖，逐级下钻至次微浪；配合破上通道线 + 同级天量确认
15. 底部几乎总同步、顶部各异；此前无关的序列突然同步 = 大事预警
16. 长线建仓点 = 大级别第五浪后整轮调整的终点；确认信号 = 自低点起第一轮五浪上升（1938.3.31 → 121.54 实例）

### 论证链
类比推理（自然规律→人类行为→股市；人体"五"类比）承重最大但证明力最弱，作者态度诚实（自认宇宙之谜）；历史指数回溯分解（图 12-15 逐级下钻、图 57-61 五个中浪、图 62-68 熊市复盘）是最强证据，但属单一历史样本事后标注；演绎展开（公理→子浪结构→通道落点）内部一致；证据形态为"规则 + 例外限定词 + 选定案例"，无频率统计、无对照组。

## 3. 批判 (Critical) ★

### 时代局限
- 数据前提：日记录 1928 年起、60 分钟记录 1932 年起；平行尺手工作图；换手率分母是 NYSE 流通股；席位价格指标已随制度消亡
- 样本前提：证据取自 1854-1938 美股（密集在 1921-1938 道指）；特大超级循环浪计数仅系于埃克斯-霍顿单一数据源
- 决定论自然观："掌握规律即可预测"的拉普拉斯式信条，与随机过程/有效市场视角冲突
- 政策市背景：把 1931-36 财政赤字、联邦开支当自然波浪（实为胡佛-罗斯福更替、放弃金本位、新政产物）

### 立场盲点
- 事后归因：全部浪标画在既成走势上；自认调整形态"很难准确预测"却未给事前判定程序
- 异常即扩张：遇到新走势以新术语（追加浪、补充循环浪、不规则顶）吸收，而非给出旧规则失效条件——补丁生成器使体系趋于不可证伪
- 无错误处理：全书无数错浪如何发现/修正/止损的规程（点评者以"右侧判定"补洞恰证缺位）
- 根基层不确定：1857-1928"很有可能是第三浪或第五浪"——底层模糊与"预测到日和小时"的顶层精确倒挂

### 未被证明的假设
1. "为什么是五"（作者明示不解释）；2. 心理波浪假设（无心理学证据）；3. 无限分形（递归无边界是断言）；4. 形态对消息免疫（消息只改幅度时长不改浪数）；5. 通道约束力（手画平行线对价格有预测力、"附近"无量化）；6. 形态→强度因果（平台=强势仅一例支撑）；7. 成交量五浪规律（长期序列代替逐浪数据）；8. 全称量词（"一定""永远不会"）无频率标注

### 最强反对意见
1. **不可证伪风险**：延长浪/不规则调整/失败浪/巧合三角构成兜底类别网 + 浪级可自由升降 → 任何已完成走势都能被纳入八浪循环，理论更接近解释系统而非可检验预测系统
2. **点评者的收编**【点评】：'优秀的交易者从不预测，只是跟随'；剔除精准预测野心、只做宏观趋势判定 + 右侧判定，等于承认原核心承诺（确定每浪终点）不可兑现；并警告心理催眠式误判风险
3. **幅度维度缺失**：全部规则只约束形态与时间，无点位/幅度算法（点评者亦承认），仅凭结构规则不构成完整交易系统
4. **判别工具在最需要时失效**：裁决歧义依赖成交量，但"市场异常疲弱时量信号可信度下降"、极清淡时 60 分钟图具欺骗性
