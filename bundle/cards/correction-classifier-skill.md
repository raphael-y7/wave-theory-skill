## I — 方法论自述

这套方法把调整浪从"杂乱回调"升格为**可分类、可读出后市信息**的结构。核心动作分两步：

1. **分类（几何判型）**：取一段走完（或接近走完）的三浪调整 A-B-C，只看两个相对位置——浪 B 有没有回到/越过调整起点、浪 C 相对浪 A 的低点在哪。四种组合对应四类：B 没回来且 C 创新低=之字形；B 回到起点且 C 与 A 持平=平台形；B 冲过起点创新高且 C 跌破 A=不规则形(1)；B 只到起点附近且 C 不破 A=不规则形(2)。同一套几何在所有浪级重复（小级别到中浪/大浪级同形）。
2. **预警（强度分级）**：走完的形态对随后行情强度分级——之字形=一般；平台形=较长强劲波动；调整终点明显高于 a 低点（调整极浅）=超级强势。熊市方向镜像：反弹质量按同样几何评估，B 失守起点且 C 反弹乏力=超级弱势。

定位约束：作者自认调整浪形成过程中很难准确预测形态与幅度，所以这套判别卡是**走完后的预警器**，不是事前预测器；建仓决策等形态确认后再做。

## A1 — 原书案例

**案例一：图 20-29 四分类同形放大演示（第五章；case_nature：示意图例）**
输入：三浪调整 A-B-C 的三种浪级图例（小级图 20-23、较大级图 24-26、中浪/大浪级图 27-29）。执行：按 B/C 相对位置逐图判型——图 20 之字形（A 陡跌、B 反弹约半、C 创全程新低）；图 21 平台形（B 回到起点附近、C 与 A 持平）；图 22 不规则形(1)（B 创新高、C 跌破 A 为全程最低）；图 23 不规则形(2)（B 不创新高、C 高于 A 且下行较缓）；图 24-29 展示较大级别中 A/B/C 的 5-3-5 细分与判型锚点（B 触及前顶水平线）。结论：四大类判别几何跨浪级不变。纯示意，无真实数据，实际结果未说明。

**案例二：1933.7-1934.7 大浪 4 平台形——"平台形=强势"的实证（第五章；case_nature：作者转述）**
输入：1933 年 7 月至 1934 年 7 月 DJIA 的大浪 4 调整。执行：按判别几何归为平台形调整（B 几乎收复 A 全部跌幅、C 与 A 低点相当）。结论：作者点名此例作为"平台形调整→后市较长强劲波动"规则的对照实例。注意：这是书中该命题被明确指认的主要实证，实质仅此一例，且属事后标注；形态→强度因果无统计频率支撑。

**案例三：图 58 中浪 2 的 A-B-C 平台形特征（第八章；case_nature：作者转述）**
输入：DJIA 周线 1923.3-1924.5 的中浪 2。执行：识别其 A 浪下跌、B 浪反弹（明显低于起始高位）、C 浪再跌收尾，C 点与 A 点低点大体相近。结论：呈现平台形判别特征（C 与 A 低点相近），是四分类几何在实盘周线上的图证之一；同段走势同时验证"偶数浪细分三子浪"。

## A2 — 未来触发

1. **判断一段回调属于什么形态**：用户说"这段回调是之字形还是平台形 / B 浪创了新高算什么 / what type of correction is this"。
2. **用调整形态读后市强度**：用户问"这个调整走完后行情会强还是弱 / 平台形是不是说明后面很强势 / how strong is the next move"。
3. **评估熊市反弹质量**：用户说"这波反弹算强吗 / B 浪都跌破前低了 / is this bear market rally strong"。
4. **建仓前的形态确认**：用户想等调整走完再买，问"现在这个 a-b-c 走完了吗，属于哪类 / has the correction ended"。
5. **区分调整形态的边界情形**：用户拿着两个相似回调图问差异，"这两个调整为什么预后不同"。

**与相邻卡区分**：
- `correction-classifier-skill` 管**调整浪整体分类**（之字/平台/不规则的判型+强度预警）；`triangle-alternation` **专查三角形**（必含五浪、楔形仅作浪 5）与交替规则——三角形不在本卡四分类展开范围内（书中归为四大类之一，但规则束独立成卡）。
- `wave-labeling-skill` 是前置计数系统，只确认"偶数浪=三浪"这层数目；判型在本卡。
- `extension-reversal` 管延长浪专属程序（两次反转）；不规则顶（B 超前顶）的杀跌推演在其规律(5)分支，本卡只做形态归类。
- `bear-diagnosis-skill` 管熊市阶段诊断与长线建仓点确认；本卡的熊市镜像判别（图 38-41）只是形态强度读数，不做阶段定位。

## E — 执行步骤

**输入契约**（缺失先问）：① 一段已识别为三浪的调整 A-B-C 及其转折点价位（最高/最低价口径，与数浪口径保持一致）；② 调整起点（前一轮运动的顶/底）位置；③ 方向语境（牛市中的向下调整，还是熊市中的向上反弹）。

1. **完成度检查（判停点）**（完成标准：明确回答调整是否走完/接近走完）。形态仍在进行中且 C 浪未展开或起点未定→**停止判型**，声明"作者自认形成过程中很难准确预测形态与幅度"，只输出当前可观察的 B 位置中间读数，不押注最终类型；用户要求事前预测时明确拒绝并说明边界。
2. **几何判型**（完成标准：B 相对起点、C 相对 A 的两个读数各给出"高于/持平/低于"，并按判别表落型）。边界情形（B 是否"创新高"、C 是否"破 A"以数据极值判定，容差须与用户事先约定，原书无量化）；不规则形(2)的依据仅为图 23 图例，输出时注明。
3. **强度分级**（完成标准：给出 一般/强势/超级强势 或熊市镜像 一般/强势/超级弱势 中的一档+判型依据）。
4. **输出契约**：判别记录一条，含（a）A-B-C 拐点价位表；（b）类型+两个几何读数；（c）后市强度预期档位；（d）不确定性声明——判型基于事后几何，形态→强度因果仅个别历史例支撑（平台形=强势的书中主实证为 1933.7-1934.7 大浪 4 一例），且无幅度算法；本输出为预警参考，不构成入场指令。

## B — 边界

**不要使用的场景**：调整浪未走完时抢跑判型并提前下单；无趋势横盘市（点评者主张，非艾略特原文：整理形态不必用波浪理论）；把强度档位当作幅度/点位预测。

**书中警告的失效模式（反例块消化）**：
- **事前无法锁定类型（x-p2-10）**：作者自认形成过程中"很难准确预测其具体形态和波动幅度"，中途押注等于赌未定形态；判型定位为走完后的预警器，建仓等形态确认后再行动。
- **教科书形态与真实斜率差异巨大（x-p2-02，【点评】）**：简图的 45 度主浪在现实中可能不足 20 度、下跌可能高达 80 度，"知道它下跌，不知道它这样下跌"——只认结构（浪数与相对位置），不预设斜率与幅度比例（现代点评者主张，非艾略特原文）。
- **最高点离场不切实际（x-p2-16，【点评】）**：顶部只能由"后续不再创新高"事后确认，右侧确认必有利润回吐；按此接受回吐预算，不以卖在最高点为决策基准（现代点评者主张，非艾略特原文）。
- **判型依据本身的松散**：不规则形(2)在正文无文字定义、仅见图 23；平台形在书中两处图例（图 21 C 与 A 持平、图 28 C 低于 A 且为全图最低）并不一致，判型应以"B 触及前顶"为纲；现代分类（锯齿/平台/三角形/联合形）与本书四分类术语不对齐，检索现代资料须防混同。

**来自阶段 0 批判节的盲点**：① **形态→强度因果是全书最弱证明环节之一**——"平台=强势"仅一例支撑、无频率统计；② 幅度维度缺失——四分类只给方向性强度读数，无任何回撤比例或目标幅度算法；③ 事后归因——全部判型画在既成走势上，事中判定无程序（作者自认）；④ 不可证伪风险——判不出时体系可改挂其他类别（不规则、追加浪等兜底概念），失效条件未给出。

**时代背景**：本书为 1938 年美股背景，图例与实证取自 1921-1938 道指；"强度预警"基于当时单一市场样本，迁移到现代市场（含 A 股）或个股时因果链未经验证，需自行留存判型-验证记录。
